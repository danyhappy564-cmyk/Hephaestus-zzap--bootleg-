[구분선]

■ 어떤 모드인가요

상인 "헤파이스토스"(영어 게임에서는 Hephaestus)가 하나 추가됩니다.
무기 수정 화면에서 저장해 둔 프리셋을 이 상인이 부품까지 다 끼운 완성 총으로 팝니다.
가격은 그 프리셋 부품들의 플리마켓 시세를 합친 값에서 90% 할인한 값이고, 기본 화폐는 유로입니다.
예를 들어 테스트한 기본 프리셋 하나는 102유로, 루블로 바꾸면 13,667루블이었습니다.
상인은 처음부터 열려 있고, 신뢰도 1단계에서 바로 살 수 있습니다.

원래 SPT 3.7용 모드라 4.1에서는 아예 켜지지 않았습니다. 4.1용으로 새로 옮기면서 원래 있던 문제들도 같이 고쳤습니다.

■ 고친 것

1) 상인 물건을 만들 때 내 프리셋이 몰래 바뀌던 문제
- 언제: 상인 화면을 열거나 아이템을 옮길 때마다
- 왜: 원래 모드는 상인에 올릴 물건을 만들 때 복사본이 아니라 내가 저장한 프리셋 원본을 직접 고쳐 썼습니다. 그래서 프리셋의 첫 부품 정보가 상인용 값으로 바뀐 채 저장될 수 있었습니다.
- 이제: 복사본으로만 물건을 만들어서 저장해 둔 프리셋은 전혀 건드리지 않습니다.
- 확인: 실제 서버를 띄워 시험해서 프리셋이 그대로인 것을 확인했습니다. 게임 화면에서는 아직 확인 못 했습니다.

2) 여럿이 같이 하는 서버에서 남의 프리셋이 팔리던 문제
- 언제: 한 서버에 계정이 여러 개일 때(같이 하는 모드 등)
- 왜: 원래 모드는 상인 물건 목록이 서버 전체에 하나뿐이라, 마지막에 접속한 사람의 프리셋으로 모두의 상인 물건이 통째로 바뀌었습니다.
- 이제: 사람마다 자기 프리셋만 보이고 자기 것만 살 수 있습니다.
- 확인: 실제 서버에서 계정 두 개로 시험해서, 다른 사람 프리셋이 안 보이는 것을 확인했습니다. 같이 하는 모드를 깐 환경에서는 아직 확인 못 했습니다.

3) 가격이 계속 바뀌고 서버가 쓸데없이 일하던 문제
- 언제: 가방 정리, 아이템 이동 같은 거의 모든 행동을 할 때마다
- 왜: 원래 모드는 그때마다 상인 물건을 처음부터 다시 만들었고, 가격도 매번 무작위로 조금씩 흔들었습니다.
- 이제: 상인 화면을 열 때와 살 때만 만들고, 가격은 무작위 없이 시세 합으로 고정이라 다시 열어도 같습니다.
- 확인: 실제 서버에서 여러 번 다시 열어도 같은 가격인 것을 확인했습니다.

4) 지운 모드의 부품이 든 프리셋 때문에 상인 화면이 깨질 수 있던 문제
- 언제: 다른 모드의 총이나 부품으로 프리셋을 만든 뒤 그 모드를 지웠을 때
- 왜: 서버에 없는 물건을 상인에 올리려 하면 상인 화면이 제대로 안 열릴 수 있습니다.
- 이제: 그런 프리셋은 건너뛰고 나머지만 팝니다.
- 확인: 자체 검사로만 확인했고, 게임에서는 아직 확인 못 했습니다.

5) 가격이 소수점이나 0원으로 나오던 경우
- 이제: 가격은 항상 정수이고 최소 1입니다. 시세를 하나도 못 구한 프리셋은 대체 가격(기본 123)에 할인을 적용합니다.
- 확인: 실제 서버에서 사 보니 표시된 가격만큼 정확히 빠지고, 총이 부품까지 다 달린 채 창고에 들어오는 것을 확인했습니다. 두 번 사도 문제없었습니다.

6) 서버 버전 범위를 넓힘
- 처음에 4.1.6 전용으로 묶어 뒀습니다. 그런데 서버가 자기 버전을 4.1.5로 알리면 이 모드뿐 아니라 서버의 다른 모드까지 전부 안 켜지는 것을 시험 중에 발견했습니다.
- 이제 4.1.5 이상 4.2 미만이면 켜집니다.

■ 새로 생긴 것

1) 한국어/영어 자동
- 게임 언어가 한국어면 상인 이름이 "헤파이스토스", 설명도 한국어로 나옵니다. 다른 언어면 원래 영어 문구 그대로입니다.
- 서버 창에 나오는 글도 서버 컴퓨터의 윈도우가 한국어면 한국어로 나옵니다.
- 확인: 실제 서버에서 한국어/영어/러시아어 문구가 맞게 나가는 것을 확인했습니다. 게임 화면에서 보이는지는 아직 확인 못 했습니다.

2) F12 설정 화면 (설치는 선택)
- F12에서 "할인율 (%)", "가격 화폐"(유로/루블/달러), "대체 가격", "서버 디버그 로그"를 바꿀 수 있습니다.
- 값을 바꾸면 서버 설정 파일에 바로 저장됩니다. 서버를 다시 켤 필요 없이 상인 화면만 다시 열면 새 가격이 나옵니다.
- 맨 아래 "서버 연결 상태" 칸에 저장이 됐는지 나옵니다.
- F12 화면 글자는 "자동"이면 게임 언어를 따라가고, 게임이 아직 언어를 정하기 전에는 윈도우 언어를 씁니다. 한국어나 English로 고정할 수도 있습니다.
- 게임이 업데이트돼도 이 화면 때문에 게임이 안 켜지는 일은 없게 만들었습니다. 최악의 경우 언어 감지만 윈도우 언어로 바뀝니다.
- 확인: 서버 쪽 저장은 실제 서버에서 확인했습니다. F12 화면 자체가 잘 뜨고 저장되는지는 아직 게임에서 확인 못 했습니다.

혹시 F12 화면 쪽이 이상하면 BepInEx 플러그인 폴더의 헤파이스토스 클라이언트 파일 하나만 지우세요. 상인은 서버 모드만으로 그대로 동작하고, 설정은 서버 모드 폴더의 설정 파일을 메모장으로 고치면 됩니다.
모드를 완전히 빼려면 서버 모드 폴더와 그 파일을 지우면 됩니다. 이미 산 총은 창고에 그대로 남는 게 정상입니다(아직 확인 못 함).

■ 사용법

1. 무기 수정 화면에서 총을 맞춘 뒤 프리셋으로 저장합니다.
2. 헤파이스토스 상인을 열면 그 프리셋이 완성 총으로 올라와 있습니다.
3. 프리셋을 새로 저장하거나 지운 뒤에는 상인 화면을 한 번 나갔다 다시 열면 반영됩니다.

■ 설치

zip을 SPT 설치 폴더(예: E:\SPT 4.1)에 풀어서 덮어쓰기 하면 서버 모드와 F12 플러그인이 제자리에 들어갑니다.
예전 3.7용 헤파이스토스 폴더가 남아 있으면 지워 주세요.
서버를 켰을 때 서버 창에 "상인 추가 완료"(영어 윈도우는 trader added)가 나오면 정상입니다.
