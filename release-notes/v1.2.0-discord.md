## Hephaestus 1.2.0

**- 내가 저장한 무기 프리셋을 부품까지 그대로 파는 상인 "헤파이스토스", SPT 4.1용**

■ 기능
- 저장한 프리셋을 완성 총으로 판매. 가격은 부품 시세 합에서 90% 할인(기본 유로, 예: 102유로)
- 게임 언어가 한국어면 상인 이름·설명이 한국어, 그 외는 영어
- F12(선택 설치)에서 할인율·화폐(유로/루블/달러)·대체 가격 변경, 상인 화면 다시 열면 바로 적용

■ 원본에서 고친 것
- 상인 물건을 만들 때 내 프리셋 원본이 몰래 바뀌던 것 → 복사본으로만 작업 (서버 시험 확인)
- 여럿이 쓰는 서버에서 마지막 접속자 프리셋이 모두에게 팔리던 것 → 각자 자기 것만 (서버 시험 확인)
- 아이템 옮길 때마다 가격이 무작위로 바뀌던 것 → 열 때만 만들고 가격 고정 (서버 시험 확인)
- 지운 모드 부품이 든 프리셋 때문에 상인 화면이 깨질 수 있던 것 → 그 프리셋만 건너뜀
- 소수점·0원 가격 → 정수, 최소 1. 구매 시 표시 가격만큼 정확히 빠짐 (서버 시험 확인)

■ 사용법
- 무기 수정 화면에서 프리셋 저장 → 헤파이스토스 상인 열기 (새로 저장했으면 다시 열기)

■ 설치
- zip을 SPT 폴더에 풀어서 덮어쓰기. 예전 3.7용 폴더가 있으면 삭제
- 서버 창에 "상인 추가 완료"가 나오면 정상

■ 주의
- 실제 서버를 띄워 시험은 끝났지만, 게임 화면과 F12 화면은 아직 직접 확인 못 했습니다. 이상하면 알려 주세요
- F12 쪽이 이상하면 BepInEx 플러그인 폴더의 헤파이스토스 파일만 지우면 됩니다 (상인은 그대로 동작)
